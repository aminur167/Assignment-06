# 🎯 DigiTools - Premium Digital Tools Marketplace

**DigiTools** is a modern, high-performance web platform designed for professionals and creators to explore and purchase premium digital assets. It provides a seamless interface to browse AI tools, design templates, and productivity software, allowing users to manage their selections through an interactive shopping cart.

## ✨ Key Features
1. **Dynamic Cart Management:** Users can add tools to their cart with a single click. The cart count in the navigation bar updates in real-time, and duplicate selections are automatically prevented with helpful alerts.
2. **Seamless Section Toggling:** The application features an intuitive toggling system that allows users to switch between the "Available Products" grid and the "Selected Cart" view instantly without any page reloads.
3. **Interactive User Feedback:** Integrated with **React-Toastify**, the platform provides immediate visual feedback for every action, such as adding items, removing products, or completing a checkout.

## 🛠 Technologies Used
- **React.js (v19):** Leveraging the latest `use()` hook and `Suspense` for efficient data fetching and state management.
- **Tailwind CSS (v4):** Utilizing a utility-first approach for a clean, professional, and responsive design.
- **DaisyUI:** For high-quality, accessible UI components like buttons, cards, and navbars.
- **React-Toastify:** To provide interactive and beautiful notification alerts.
- **JSON Data:** To manage product information dynamically.
